# Bug Reports - AcademyBugs & MRBUGGY7

## Opis projektu

Projekt zawiera zestaw manualnych zgłoszeń błędów przygotowanych podczas testowania aplikacji webowych AcademyBugs oraz MRBUGGY7.

Celem było identyfikowanie nieprawidłowości w działaniu aplikacji, ich dokumentowanie oraz przygotowanie raportów umożliwiających odtworzenie i weryfikację zgłoszonych problemów.

## Zakres testów

Przetestowane obszary:

- **AcademyBugs**
  - wyświetlanie produktów
  - dodawanie komentarzy
  - zmiana waluty i aktualizacja ceny produktu
  - responsywność interfejsu

- **MRBUGGY7**
  - walidacja pól formularzy
  - walidacja numeru telefonu
  - wyszukiwanie z uwzględnieniem spacji
  - wyszukiwanie z uwzględnieniem wielkości liter
  - odświeżanie listy po usunięciu elementu
  - responsywność interfejsu
  - działanie skrótów klawiszowych

## Rodzaj testów

- Testy manualne
- Testy funkcjonalne
- Testy pozytywne i negatywne
- Testy walidacyjne
- Testy responsywności
- Testy scenariuszy użytkownika

## Dokumentacja

Zgłoszenia błędów zostały przygotowane w formie raportów zawierających:

- ID błędu
- tytuł zgłoszenia
- opis problemu
- kroki odtworzenia
- oczekiwany rezultat
- rzeczywisty rezultat
- priorytet / severity
- środowisko testowe

## Narzędzia

- Jira - dokumentacja i zarządzanie zgłoszeniami błędów
- Chrome DevTools - wsparcie podczas testowania
- GitHub - przechowywanie dokumentacji projektu

## Status projektu

Zgłoszenia błędów przygotowane jako element portfolio QA Junior.
