# Test Cases - Allegro

## Opis projektu

Projekt zawiera zestaw manualnych przypadków testowych przygotowanych dla serwisu Allegro.
Celem było przetestowanie kluczowych funkcjonalności z perspektywy użytkownika oraz przygotowanie dokumentacji testowej zgodnej z praktykami stosowanymi w procesie QA.

## Zakres testów

Przetestowane obszary:

* **Wyszukiwanie produktów**

  * wyszukiwanie poprawnej frazy
  * wyszukiwanie pustej frazy
  * obsługa braku wyników
  * podstawowe scenariusze filtrowania

* **Logowanie i konto użytkownika**

  * logowanie poprawnymi danymi
  * logowanie błędnym hasłem
  * logowanie nieistniejącym kontem
  * walidacja pustego formularza

* **Koszyk**

  * dodawanie produktu do koszyka
  * zmiana ilości produktu
  * usuwanie produktu
  * obsługa pustego koszyka
  * przejście do zakupu dla użytkownika zalogowanego i niezalogowanego

## Rodzaj testów

* Testy manualne
* Testy funkcjonalne
* Testy pozytywne i negatywne
* Walidacja podstawowych ścieżek użytkownika (user flow)

## Dokumentacja

Przypadki testowe zostały przygotowane w arkuszu Excel i zawierają:

* ID testu
* priorytet
* nazwę przypadku testowego
* dane testowe
* warunki wstępne
* kroki wykonania
* oczekiwany rezultat
* status wykonania
